# AI instructions

`SyncAiInstructions.bat` writes the framework's AI instructions into the root of your solution, in
the version of the `Pillaro.Dataverse.PluginFramework` package this project uses. Claude Code,
GitHub Copilot and Codex then work by the same rules.

Run it once after creating the solution from the Visual Studio template, and again after every
package update. A solution created with `dotnet new` already has the instructions.

```text
Tools\AI\SyncAiInstructions.bat           write or update the instructions
Tools\AI\SyncAiInstructions.bat -Check    only report whether they are out of date (exit code 3)
```

What it writes:

| Path | Owner |
|---|---|
| `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md` | yours — only the block between `pillaro:begin` and `pillaro:end` is replaced |
| `.pillaro/ai/`, `.github/instructions/pillaro-*`, `.claude/skills/pillaro-*`, `.agents/skills/pillaro-*` | the package — overwritten on every sync, do not edit |
| `.pillaro/project-setup.md` | yours — created once with the paths of your projects |

Commit all of them, so everyone on the team — and every agent — works by the same instructions.

This folder is generated by the package; do not edit these files.
